# Zombie Invasion — Neon Voxel City

Game zombie 3D (Three.js) satu file, langsung jalan di browser.

## Fitur
- Lobi menu 2D: Pilih Arena, Toko Pedang, Toko Ability
- 7 pedang, masing-masing punya super berbeda (tombol E)
- 6 special skill dibeli di Toko Ability (tombol R)
- Mode Level (berurutan, makin sulit) dan Infinity, 4 tingkat kesulitan
- Progres tersimpan di browser (localStorage)

## Deploy
Upload `index.html` ke root repo, lalu aktifkan GitHub Pages (Settings → Pages).
